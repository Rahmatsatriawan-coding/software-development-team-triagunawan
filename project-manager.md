# Project Manager

## Nama
Wawan

## Peran
Project Manager

## Tanggung Jawab

Sebagai Project Manager, bertanggung jawab untuk:

- Mengelola repository GitHub
- Mengatur kolaborasi anggota tim
- Membuat dan mengatur branch
- Memantau Pull Request
- Melakukan review kontribusi anggota
- Mengatur proses merge ke branch main

## Tim

|---|---|
| Wawan | Project Manager |
| Guntur | Front-End Developer |
| Rakhmat | Back-End Developer |
